## Purpose

Provides parsing and lowering of a strictly annotated TypeScript subset into the shared backend-agnostic `compylr` Intermediate Representation (IR).

## ADDED Requirements

### Requirement: Lowering TypeScript to Universal IR
The `typescript-frontend` capability SHALL parse TypeScript source text and lower it to the `compylr` IR, preserving structural equivalence with other frontends for identical operations.

#### Scenario: Lowering a simple function
- **WHEN** the frontend processes a TypeScript function
- **THEN** it generates an IR unit structurally equivalent to the IR generated by the Python frontend for the identical function, modulo semantic mode parameters explicitly required to preserve TypeScript semantics.
